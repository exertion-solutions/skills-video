# Skills para hacer videos con IA

Pack de skills de Claude para producir videos y reels con HTML + HyperFrames, local y gratis. Por Exertion Solutions.

## Descarga

**Pack completo (zip):** [pack-skills-video.zip](https://github.com/exertion-solutions/skills-video/raw/main/pack-skills-video.zip)

O por separado, en la carpeta [`skills/`](skills/).

## Qué incluye

| Skill | Qué hace |
|---|---|
| `edita-reels` | Voz en off (mp3) a reel vertical 1080x1920 con motion graphics, subtítulos palabra por palabra y B-roll |
| `reels-guion-brief` | Ideas con tendencias, guion, datos verificados y copy de publicación; entrega un brief para `edita-reels` |
| `brag-slim` | Proyecto o web a video corto de lanzamiento, con música, movimiento y texto para compartir |
| `real-sfx` | Diseño de sonido con efectos reales (opcional) |
| `videos-html-opus-prompts` | Videos y animaciones en código (HTML, Canvas, SVG, Three.js) a partir de prompts |
| `mascota-3d-blender-hyperframes` | Mascota 3D animada con Blender dentro de un video vertical |
| `video-perception` | Claude ve y analiza videos (archivo o link de YouTube) |

Flujo sugerido: brief → voz en off → reel → (opcional) sonido.

## Cómo usarlas

1. Descargá el archivo `.skill`.
2. Cargalo en Claude (Configuración → Skills).
3. Pedile lo que necesites con lenguaje normal, por ejemplo: "hacé un reel con este audio".

## Aclaraciones

- `real-sfx` busca sonidos en bibliotecas locales; en otra máquina usa solo los efectos libres que trae incluidos.
- `reels-guion-brief` y `mascota-3d-blender-hyperframes` están escritas con el estilo y los personajes de Exertion Solutions: adaptá esas referencias a lo tuyo.
